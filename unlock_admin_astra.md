## 1️⃣ Введение

🛡️ Эта инструкция показывает, как разблокировать администратора в Astra Linux, если учетная запись заблокирована из-за превышения количества неудачных попыток входа или забытого пароля.

<a id="access"></a>

## 2️⃣ Получение доступа к машине

<a id="grub_known"></a>

### 2.1 Если пароль GRUB известен и включено меню загрузчика

1. Перезагрузить машину.
2. Дождаться появления меню загрузчика GRUB2 и нажать **`e`** для редактирования записи.

![Screenshot](/img/faillog_remove_1.png)

4. На запрос **"Введите имя пользователя"** ввести пользователя, созданного при установке ОС (в старых системах — `root`).  
5. На запрос пароля ввести пароль загрузчика.  
6. Найти строку, начинающуюся со слова `linux`, и изменить часть:

```text
ro quiet splash
```

на:

```text
rw init=/bin/bash
```

Изменяемая часть подчеркнута на снимке экрана:

![Screenshot](/img/faillog_remove_2.png)

6. Нажать **F10**, чтобы загрузить систему и получить приглашение командной строки:
   

```text
root@(none):/#
```

> [!WARNING]
> Из официальной инструкции Astra Linux: если в строке параметров ядра указано несколько `console=...` (например, и `console=tty0` для графики, и `console=ttyS0,...` для последовательного порта) — командная оболочка подключится к **последнему** указанному `console=`. Если это последовательный порт, а не графический экран — на графическом терминале никакого приглашения командной строки не появится вообще, создавая ложное впечатление, что загрузка не удалась, хотя shell реально запущен и ждёт на serial-порту.

📌 Для перезагрузки после изменений используйте:

```bash
/sbin/reboot -f
```

### 2.2 Если пароль GRUB неизвестен или меню недоступно

По официальной инструкции Astra Linux, дальнейшие действия зависят от того, что именно доступно.

#### Вариант A — в меню GRUB есть пункт "recovery mode"

Самый простой путь, если он доступен — **не требует пароля загрузчика вообще**, только пароль администратора:

1. В меню загрузчика GRUB2 выбрать пункт с текстом `recovery mode`.
2. Ввести пароль пользователя-администратора (созданного при установке ОС) — это ПАРОЛЬ УЧЁТНОЙ ЗАПИСИ, не пароль загрузчика.
3. Если пароль подошёл — откроется командная оболочка с правами root, файловые системы уже смонтированы по `/etc/fstab`. Дальше — сразу к разделу [3. Получение имени администратора](#get_admin).
4. Если пароль не подошёл (или его тоже не помните) — перезагрузиться и перейти к варианту B.

#### Вариант B — нужна загрузка с установочного/live-носителя

Актуально, если: пункта `recovery mode` в меню нет, пароль администратора тоже неизвестен, или меню загрузчика недоступно совсем. Требует включённой в BIOS/настройках ВМ возможности загрузки со съёмного носителя.

**Astra Linux SE 1.8** (установщик astra-installer, Live-режим):

1. Загрузиться с установочного носителя, на приглашении нажать `C`, дождаться установщика, нажать `F10`, в меню выбрать «Выйти в консоль», `Enter`.
2. Определить раздел с корневой ФС: `blkid` или `lsblk`.
3. Смонтировать его (пример без LVM, `/dev/sda2`):
   ```bash
   mount /dev/sda2 /mnt
   ```
   С LVM (имена по умолчанию в Astra — группа `VG`, тома `lv_root`/`lv_home`, актуальный список — `lvm lvs`):
   ```bash
   lvm vgchange -a y
   mount /dev/VG/lv_root /mnt
   mount /dev/VG/lv_home /mnt/home
   ```
4. Для действий вроде установки пакетов доп. каталоги:
   ```bash
   mount --bind /dev /mnt/dev
   mount --bind /dev/pts /mnt/dev/pts
   mount --bind /sys /mnt/sys
   mount --bind /proc /mnt/proc
   ```
5. Перейти в корень установленной системы и выполнить нужные действия (разделы 3–6 этой статьи):
   ```bash
   chroot /mnt
   ```
6. По завершении:
   ```bash
   exit
   umount -R -l /mnt   # только если монтировали доп. каталоги в шаге 4
   ```
   Извлечь установочный носитель, затем:
   ```bash
   reboot
   ```

**Astra Linux SE 1.7 и более ранние** (классический debian-installer):

1. Загрузиться с установочного диска, выбрать язык, в меню выбрать «Режим восстановления», пройти базовую настройку (лицензия/раскладка/имя компьютера/часовой пояс).
2. Выбрать корневой раздел (обычно `/dev/sda1` для MBR или `/dev/sda2` для GPT).
3. Запустить оболочку в корневом разделе — установщик сам предложит `chroot /target`, либо выполнить вручную:
   ```bash
   chroot /target
   ```
4. Выполнить нужные действия по восстановлению (разделы 3–6 этой статьи).
5. Завершить: `Ctrl-D`, извлечь диск, перезагрузиться.

> [!NOTE]
> Источник — официальная документация Astra Linux (wiki.astralinux.ru, статьи «Режим восстановления» и «Сброс счетчика неудачных попыток входа и пароля администратора»), сверено дословно.

После входа в режим восстановления любым из способов, по завершении всех действий:

```bash
exit
reboot
```

> Не забудьте удалить установочный CD-ROM/носитель перед перезагрузкой.

<a id="get_admin"></a>

## 3️⃣ Получение имени администратора

🧾 При установке ОС создается администратор с **UID 1000**.
Если имя неизвестно, получить его можно командой:

```bash
getent passwd 1000
```

<a id="reset_failures"></a>

## 4️⃣ Сброс счетчика неудачных попыток

После доступа к системе выполнить:

* Для локальных пользователей:

```bash
faillog -r
```

* Для доменных пользователей:

```bash
faillog -u user@domain.ru -r
```

📌 Можно указывать пользователя по имени, UID или диапазону UID.

> После сброса счетчика рекомендуется перезагрузить машину.

<a id="change_pass"></a>

## 5️⃣ Смена пароля

Чтобы сменить пароль администратора:

```bash
passwd <имя_пользователя>
```

* Ввести и подтвердить новый пароль.
* После смены пароля перезагрузить ОС.

---

<a id="unlock_account"></a>

## 6️⃣ Сброс блокировки учетной записи администратора

Если локальный администратор заблокировал учетку:

1. Загрузиться в режиме восстановления.
2. Выполнить команду:

```bash
usermod -e "" <имя_пользователя>
```

* `""` — пустые двойные кавычки.
* `<имя_пользователя>` — имя учетной записи администратора.

<a id="reboot"></a>

## 7️⃣ Перезагрузка системы

После выполнения всех действий для применения изменений:

```bash
reboot
```
